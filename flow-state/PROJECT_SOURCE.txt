# Flow State

Linux desktop Pomodoro + task manager — Python, PySide6, SQLite.

## Quick start
```bash
./scripts/setup.sh      # once: creates .venv, installs PySide6 + pytest + pyinstaller
./scripts/run.sh        # start the app
./scripts/test.sh       # run tests (do this before every increment)
./scripts/build.sh      # tests + standalone ./dist/FlowState
./scripts/dump_project.sh   # regenerate PROJECT_SOURCE.txt (whole project in one .txt)
```
Manual run: `PYTHONPATH=src python -m flow_state`

Your data stays in `~/.local/share/flow-state/data.db` (unchanged from v1).
Old databases are upgraded automatically and safely by versioned migrations.

## Layout
```
src/flow_state/
├── __main__.py / app.py     entry point
├── paths.py                 data dir + bundled resources
├── core/                    pure logic (no DB, no widgets)
│   ├── timer.py             PomodoroTimer
│   └── scoring.py           ★ calculation & reward rules
├── data/                    SQL only
│   ├── database.py
│   └── migrations/          ★ 001_initial, 002_subtasks, ...
├── services/                business layer — the ONLY thing the UI calls
│   ├── task_service.py      ★ includes subtasks API
│   ├── focus_service.py
│   ├── analytics_service.py

```
★ = extension points. See **docs/ARCHITECTURE.md** for step-by-step recipes.

# Flow State — Architecture & Extension Guide

## Layers (dependencies point DOWN only)
```
ui  ──►  services  ──►  data (database + migrations)
 │           │
 └──► core ◄─┘          core = timer + scoring (no SQL, no widgets)
i18n is used by ui only.
```
Rules
1. Widgets never import `Database` and never write SQL. They receive one
   `AppServices` object (`services.tasks`, `.focus`, `.analytics`, `.folders`, `.settings`).
2. `database.py` contains SQL only — no percentages, no rewards, no Qt.
3. Every number shown to the user (rewards, rates, remaining time) comes from
   `core/scoring.py`.
4. Schema changes are new migration files; released migrations are never edited.
5. Each increment ends with `./scripts/test.sh` green.

---

## Recipe 1 — Add a language (≈10 minutes, zero code changes)
1. `cp src/flow_state/i18n/locales/fr.py src/flow_state/i18n/locales/nl.py`
2. Edit the header:
   ```python
   CODE = 'nl'; NAME = 'Nederlands'; RTL = False; QT_LOCALE = 'nl_NL'; ORDER = 12
   ```
   (`RTL = True` for Hebrew, Persian, Urdu …)
3. Translate the values of `MESSAGES` (keys are the English strings in `en.py`).
4. `./scripts/test.sh -s` — `test_report_missing_translations` prints what is still missing
   (missing keys fall back to English, never Arabic).
The language appears in Settings automatically.

New UI text? Write it in Arabic in the code, add `'arabic': 'English'` to `en.py`,
then add the English key to the other language files.

## Recipe 3 — Change the calculation / reward system
All rules live in `core/scoring.py`:

| Method | Controls |
|---|---|
| `session_fraction(elapsed, full)` | how much of a session counts when you press Finish |
| `reward_for(fraction)` | 🍅 added to the task (`completed_sessions`) |
| `evaluate_session(...)` | fraction + real focus seconds + reward together |
| `task_rate`, `time_rate`, `remaining_minutes`, `estimated_minutes` | analytics cards & donut |

Steps:
1. Subclass `ScoringPolicy`, give it a unique `name`, override what you need.
   Example already included: `FullSessionsOnlyPolicy` (only a full session earns 🍅).
2. Register it in `POLICIES`.
3. Add it to `SCORING_CHOICES` in `ui/dialogs/settings_dialog.py` (+ translations).
4. Add tests in `tests/test_scoring.py`.

The user picks the policy in Settings → "نظام الحساب" (saved as `scoring_policy`).
Focus history (`focus_sessions.focus_seconds`) always stores REAL time, so
changing the reward rule never corrupts time statistics.

Ideas for later: XP / levels / streaks → new table via a migration
(`003_rewards.py`), a `RewardService`, and `ScoringPolicy.xp_for(result)`.

## Recipe 4 — Change the database schema
1. Create `data/migrations/003_<name>.py` with `VERSION = 3` and `upgrade(conn)`.
2. Append `"003_<name>"` to `_MODULES` in `data/migrations/__init__.py`.
3. Add SQL methods in `database.py`, logic in a service, then UI.
4. Add a test that upgrades an old database (see `tests/test_database.py`).

# Flow State: Technical Audit Report (v1)

## Implemented
- Renamed the complete product identity from Focus To-Do to Flow State.
- Added 12 selectable languages: Arabic, English, French, German, Spanish, Italian, Portuguese, Turkish, Russian, Simplified Chinese, Japanese, and Korean.
- Arabic uses RTL; all other included languages use LTR.
- Added dark-mode styling for date/time editors and their controls.
- Added theme-aware checkbox indicators for checked, unchecked, hover, and disabled states.
- Preserved Light, Dark, and System appearance modes.

## Fixed bugs
1. White date and time fields in Dark Mode: fixed by styling QDateEdit, QTimeEdit, and QDateTimeEdit.
2. White native checkboxes in Dark Mode: fixed with theme-aware indicators.
3. Inconsistent product name across window, app metadata, tray, README, and build instructions: centralized under Flow State naming.
4. Western languages previously inherited RTL: language selection now updates direction.
5. Historical focus duration accuracy: new sessions use recorded focus seconds instead of recalculating from a later timer duration.
6. Existing completed tasks without completion timestamps: migrated safely with an initial timestamp so analytics do not fail.

## Known limitations
- Historical sessions created before focus_sessions existed cannot be assigned to their true original dates because that information was never stored.
- A packaged build must be created on its target OS. Linux builds do not produce native Windows or macOS binaries.
- Translation is runtime UI localization. User-created task and folder names are intentionally not translated.

## Supported desktop targets
- Linux: current primary target (Ubuntu, Debian, Linux Mint, openSUSE, ...).
- Windows: Windows 10 and Windows 11.
- macOS: macOS 13 or later, Intel and Apple Silicon.

import sys

from PySide6.QtWidgets import QApplication, QSystemTrayIcon

from flow_state import APP_NAME
from flow_state.data.database import Database
from flow_state.i18n import set_language
from flow_state.services import AppServices
from flow_state.ui.main_window import MainWindow
from flow_state.ui.theme import apply_theme
from flow_state.ui.tray import TrayController


def main():
    app = QApplication(sys.argv)
    app.setApplicationName(APP_NAME)
    tray_available = QSystemTrayIcon.isSystemTrayAvailable()
    app.setQuitOnLastWindowClosed(not tray_available)

    services = AppServices(Database())
    settings = services.settings.all()
    set_language(settings.get("language", "ar"))
    apply_theme(app, settings.get("theme_mode", "system"))

    window = MainWindow(services)
    window.show()
    if tray_available:
        window.tray_controller = TrayController(window, window.timer)
        window.tray_controller.show()
    sys.exit(app.exec())

"""Calculation & reward rules for Flow State.

Every number the app shows about progress comes from ONE policy object.
To change how progress / rewards are computed, subclass ScoringPolicy
(or edit DefaultScoringPolicy) and register it in get_policy().
No UI or database code needs to change.
"""
from dataclasses import dataclass


@dataclass(frozen=True)
class SessionResult:
    """Outcome of one focus period, produced by the policy."""
    fraction: float        # part of a full work session (0..1), 2 decimals
    focus_seconds: int     # real focused seconds to store in history
    reward: float          # what is added to task.completed_sessions (🍅)


class ScoringPolicy:
    """Base policy. Override any method to change the rules."""

    name = "base"

    # ---- focus sessions -------------------------------------------------
    def session_fraction(self, elapsed_seconds: float, full_seconds: float) -> float:
        if full_seconds <= 0:
            return 0.0
        return round(max(0.0, min(1.0, elapsed_seconds / full_seconds)), 2)

    def evaluate_session(self, fraction: float, work_seconds: int) -> SessionResult:
        fraction = round(max(0.0, min(1.0, float(fraction))), 2)
        seconds = max(0, round(fraction * work_seconds))
        return SessionResult(fraction, seconds, self.reward_for(fraction))

    def reward_for(self, fraction: float) -> float:
        """Tomatoes earned for a session. Default: proportional."""
        return round(fraction, 2)

    # ---- analytics ------------------------------------------------------
    @staticmethod
    def percent(part: float, whole: float) -> int:
        return min(100, round(part * 100 / whole)) if whole else 0

    def task_rate(self, done: int, total: int) -> int:
        return self.percent(done, total)

    def estimated_minutes(self, estimated_sessions: float, work_minutes: int) -> float:
        return float(estimated_sessions or 0) * work_minutes

    def remaining_minutes(self, total_minutes: float, elapsed_estimated_minutes: float) -> float:
        return max(0.0, total_minutes - elapsed_estimated_minutes)

    def time_rate(self, elapsed_estimated_minutes: float, total_minutes: float) -> int:
        return self.percent(elapsed_estimated_minutes, total_minutes)


class DefaultScoringPolicy(ScoringPolicy):
    """Current Flow State behaviour (identical to v1)."""
    name = "default"


class FullSessionsOnlyPolicy(ScoringPolicy):
    """Example alternative: only a finished session (>= 100%) earns a tomato."""
    name = "full_sessions_only"

    def reward_for(self, fraction: float) -> float:
        return 1.0 if fraction >= 1.0 else 0.0


POLICIES = {p.name: p for p in (DefaultScoringPolicy, FullSessionsOnlyPolicy)}


def get_policy(name: str = "default") -> ScoringPolicy:
    return POLICIES.get(name, DefaultScoringPolicy)()

===== FILE: ./src/flow_state/core/timer.py =====
from PySide6.QtCore import QObject, QTimer, Signal

from flow_state.core.scoring import ScoringPolicy, get_policy


class PomodoroTimer(QObject):
    tick = Signal(str, int)
    mode_changed = Signal(str, int)
    finished = Signal(str)
    skipped = Signal(str)
    running_changed = Signal(bool)
    period_ended = Signal(str, float)

    VALID_MODES = {"work", "short_break", "long_break"}

    def __init__(self, settings: dict, policy: ScoringPolicy = None):
        super().__init__()
        self.policy = policy or get_policy()
        self.timer = QTimer(self)
        self.timer.setInterval(1000)
        self.timer.timeout.connect(self._on_tick)
        self.settings = {}
        self.mode = "work"
        self.remaining_seconds = 0
        self.completed_work_sessions = 0
        self.update_settings(settings)
        self.remaining_seconds = self.duration_for_mode(self.mode)

    def update_settings(self, settings: dict):
        def positive_int(key, default):
            try:
                return max(1, int(settings.get(key, default)))
            except (TypeError, ValueError):
                return default
        self.settings = {
            "work_duration": positive_int("work_duration", 25),
            "short_break": positive_int("short_break", 5),
            "long_break": positive_int("long_break", 15),
            "sessions_before_long_break": positive_int("sessions_before_long_break", 4),
        }

    def duration_for_mode(self, mode):
        if mode == "work":
            return self.settings["work_duration"] * 60
        if mode == "short_break":
            return self.settings["short_break"] * 60
        if mode == "long_break":
            return self.settings["long_break"] * 60
        raise ValueError(f"Unknown timer mode: {mode}")

    def start(self):
        if self.remaining_seconds <= 0:
            self.remaining_seconds = self.duration_for_mode(self.mode)
            self.emit_state()
        if not self.timer.isActive():
            self.timer.start()
            self.running_changed.emit(True)

    def pause(self):
        if self.timer.isActive():
            self.timer.stop()
            self.running_changed.emit(False)

    def is_running(self):
        return self.timer.isActive()

    def reset(self, reset_sessions=False):
        self.pause()
        self.mode = "work"
        if reset_sessions:
            self.completed_work_sessions = 0
        self.remaining_seconds = self.duration_for_mode(self.mode)
        self.mode_changed.emit(self.mode, self.completed_work_sessions)
        self.emit_state()

    def reset_current_period(self):
        self.pause()
        self.remaining_seconds = self.duration_for_mode(self.mode)
        self.mode_changed.emit(self.mode, self.completed_work_sessions)
        self.emit_state()

    def set_mode(self, mode):
        if mode not in self.VALID_MODES:
            raise ValueError(f"Unknown timer mode: {mode}")
        self.pause()
        self.mode = mode
        self.remaining_seconds = self.duration_for_mode(mode)
        self.mode_changed.emit(self.mode, self.completed_work_sessions)
        self.emit_state()

    def skip(self):
        was_running = self.timer.isActive()
        self.skipped.emit(self.mode)
        self._move_to_next_period(completed=False)
        if was_running:
            self.timer.start()

    def finish_early(self):
        old_mode = self.mode
        full = self.duration_for_mode(old_mode)
        elapsed = max(0, full - self.remaining_seconds)
        fraction = self.policy.session_fraction(elapsed, full) if old_mode == "work" else 0.0
        self.pause()
        self.period_ended.emit(old_mode, fraction)
        self._move_to_next_period(completed=False)

    def _on_tick(self):
        if self.remaining_seconds <= 0:
            return
        self.remaining_seconds -= 1
        if self.remaining_seconds == 0:
            old_mode = self.mode
            self.period_ended.emit(old_mode, 1.0 if old_mode == "work" else 0.0)
            self.finished.emit(old_mode)
            self._move_to_next_period(completed=True)
        else:
            self.emit_state()

    def _move_to_next_period(self, completed):
        if self.mode == "work":
            if completed:
                self.completed_work_sessions += 1
            if completed and self.completed_work_sessions % self.settings["sessions_before_long_break"] == 0:
                self.mode = "long_break"
            else:
                self.mode = "short_break"
        else:
            self.mode = "work"
        self.remaining_seconds = self.duration_for_mode(self.mode)
        self.mode_changed.emit(self.mode, self.completed_work_sessions)
        self.emit_state()

    def formatted_time(self):
        minutes, seconds = divmod(max(0, self.remaining_seconds), 60)
        return f"{minutes:02d}:{seconds:02d}"

    def emit_state(self):
        self.tick.emit(self.formatted_time(), self.remaining_seconds)

            params.append(folder_id)
        if priority_filter is not None:
            query += " AND tasks.priority = ?"
            params.append(priority_filter)
        today = "date('now', 'localtime')"
        if selected_date:
            if completed_filter is True:
                query += " AND date(tasks.completed_at) = date(?)"
                params.append(selected_date)
            else:
                query += (" AND date(COALESCE(tasks.start_at, tasks.due_at)) <= date(?)"
                          " AND date(COALESCE(tasks.end_at, tasks.due_at)) >= date(?)")

        elif date_filter == "upcoming":
            query += f" AND date(tasks.due_at) > {today}"

            query += " AND datetime(tasks.due_at) < datetime('now', 'localtime')"

            completed_filter = True
        if completed_filter is not None:
            query += " AND tasks.completed = ?"
            params.append(1 if completed_filter else 0)
        query += " ORDER BY completed ASC, due_at IS NULL ASC, due_at ASC, priority DESC, id DESC"

def upgrade(conn):

        id INTEGER PRIMARY KEY, name TEXT NOT NULL)""")
    conn.execute("""CREATE TABLE IF NOT EXISTS tasks (
        id INTEGER PRIMARY KEY,
        folder_id INTEGER,
        title TEXT NOT NULL,
        priority INTEGER DEFAULT 0,
        completed INTEGER DEFAULT 0,
        is_current INTEGER DEFAULT 0,
        notes TEXT DEFAULT '',
        due_at TEXT DEFAULT NULL,
        start_at TEXT DEFAULT NULL,
        end_at TEXT DEFAULT NULL,
        estimated_sessions INTEGER DEFAULT NULL,
        completed_sessions REAL DEFAULT 0,
        completed_at TEXT DEFAULT NULL,
        FOREIGN KEY(folder_id) REFERENCES folders(id) ON DELETE CASCADE)""")
    conn.execute("""CREATE TABLE IF NOT EXISTS tags (
        id INTEGER PRIMARY KEY, name TEXT UNIQUE NOT NULL)""")
    conn.execute("""CREATE TABLE IF NOT EXISTS task_tags (
        task_id INTEGER, tag_id INTEGER,
        PRIMARY KEY(task_id, tag_id),
        FOREIGN KEY(task_id) REFERENCES tasks(id) ON DELETE CASCADE,
        FOREIGN KEY(tag_id) REFERENCES tags(id) ON DELETE CASCADE)""")
    conn.execute("""CREATE TABLE IF NOT EXISTS focus_sessions (
        id INTEGER PRIMARY KEY,
        task_id INTEGER,
        fraction REAL NOT NULL,
        focus_seconds INTEGER NOT NULL,
        created_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
        FOREIGN KEY(task_id) REFERENCES tasks(id) ON DELETE SET NULL)""")
    conn.execute("""CREATE TABLE IF NOT EXISTS settings (
        key TEXT PRIMARY KEY, value TEXT)""")
    # Columns added during v1 development (old databases may miss them).
    existing = column_names(conn, "tasks")

    conn.execute("UPDATE tasks SET start_at = COALESCE(start_at, due_at), "
                 "end_at = COALESCE(end_at, due_at) WHERE due_at IS NOT NULL")

"""Versioned schema migrations.

Each migration is a module named NNN_description.py exposing
    VERSION: int
    def upgrade(conn): ...
The current version is stored in `PRAGMA user_version`.
To add a migration: create the next numbered file and append it to MIGRATIONS.
Never edit a migration that has already been released.
"""
import importlib

_MODULES = [
    "001_initial",
    "002_subtasks",
]

MIGRATIONS = [importlib.import_module(f"{__name__}.{m}") for m in _MODULES]


def current_version(conn) -> int:
    return conn.execute("PRAGMA user_version").fetchone()[0]


def migrate(conn) -> int:
    version = current_version(conn)
    for module in sorted(MIGRATIONS, key=lambda m: m.VERSION):
        if module.VERSION > version:
            with conn:
                module.upgrade(conn)
                conn.execute(f"PRAGMA user_version = {int(module.VERSION)}")
            version = module.VERSION
    return version


def column_names(conn, table):
    return {row[1] for row in conn.execute(f"PRAGMA table_info({table})")}

"""Runtime UI localization.

Source strings in the code are Arabic. `en` maps Arabic -> English, and every
other language maps English -> target. Missing translations fall back to
English (never to Arabic). Qt is imported lazily so this module is testable
without a display.
"""
from functools import lru_cache

from flow_state.i18n.locales import load_packs

PACKS = load_packs()
SOURCE = "ar"
PIVOT = "en"
LANGUAGES = {code: pack.NAME for code, pack in PACKS.items()}
RTL = {code for code, pack in PACKS.items() if pack.RTL}
_current = SOURCE


def _pivot():
    return PACKS[PIVOT].MESSAGES


def set_language(code):
    global _current
    _current = code if code in PACKS else SOURCE


def language():
    return _current


def is_rtl(code=None):
    return (code or _current) in RTL


def qt_locale_name(code=None):
    return getattr(PACKS.get(code or _current), "QT_LOCALE", "en_US")


def tr(text):
    """Translate one Arabic source string to the current language."""
    if _current == SOURCE:
        return text
    english = _pivot().get(text, text)
    if _current == PIVOT:
        return english
    return PACKS[_current].MESSAGES.get(english, english)


@lru_cache(maxsize=1)
def _reverse_index():
    """visible text in ANY language -> Arabic source (prevents translating
    over already-translated text when switching languages repeatedly)."""
    reverse = {}
    for source, english in _pivot().items():
        reverse[source] = source
        reverse[english] = source
        for code, pack in PACKS.items():
            if code in (SOURCE, PIVOT):
                continue
            value = pack.MESSAGES.get(english)
            if value:
                reverse[value] = source
    return sorted(reverse.items(), key=lambda kv: len(kv[0]), reverse=True)


@lru_cache(maxsize=1)
def _sources_by_length():
    return sorted(_pivot(), key=len, reverse=True)


def translate_text(text):
    """Translate a full visible string (may contain several source phrases)."""
    if not text:
        return text
    result = text
    for visible, source in _reverse_index():
        if visible and visible in result:
            result = result.replace(visible, source)
    if _current == SOURCE:
        return result
    for source in _sources_by_length():
        if source in result:
            result = result.replace(source, tr(source))
    return result


def translate_tree(root):
    """Retranslate every label/button/combo/placeholder/header under root."""
    from PySide6.QtCore import Qt
    from PySide6.QtWidgets import QAbstractButton, QComboBox, QGroupBox, QLabel, QLineEdit, QTableWidget

    root.setLayoutDirection(Qt.RightToLeft if is_rtl() else Qt.LeftToRight)
    if hasattr(root, "windowTitle") and root.windowTitle():
        root.setWindowTitle(translate_text(root.windowTitle()))
    widgets = set()
    for cls in (QLabel, QAbstractButton, QGroupBox):
        widgets.update(root.findChildren(cls))
    for widget in widgets:
        if isinstance(widget, QGroupBox):
            widget.setTitle(translate_text(widget.title()))
        else:
            widget.setText(translate_text(widget.text()))
    for combo in root.findChildren(QComboBox):
        for i in range(combo.count()):
            combo.setItemText(i, translate_text(combo.itemText(i)))
    for line in root.findChildren(QLineEdit):
        line.setPlaceholderText(translate_text(line.placeholderText()))
    for table in root.findChildren(QTableWidget):
        for col in range(table.columnCount()):
            item = table.horizontalHeaderItem(col)
            if item:
                item.setText(translate_text(item.text()))

        if info.name.startswith("_"):

import datetime


class AnalyticsService:
    def __init__(self, db, settings, policy):
        self.db = db
        self.settings = settings
        self.policy = policy

    def summary(self):
        raw = self.db.analytics_raw()
        p = self.policy
        total_minutes = p.estimated_minutes(raw["estimated_sessions"], self.settings.work_minutes())
        elapsed = raw["focus_seconds"] / 60
        elapsed_estimated = raw["estimated_focus_seconds"] / 60
        return {
            "total_tasks": raw["total_tasks"],
            "done_tasks": raw["done_tasks"],
            "task_rate": p.task_rate(raw["done_tasks"], raw["total_tasks"]),
            "total_minutes": total_minutes,
            "elapsed_minutes": elapsed,
            "remaining_minutes": p.remaining_minutes(total_minutes, elapsed_estimated),
            "time_rate": p.time_rate(elapsed_estimated, total_minutes),
        }

    def counts(self):
        return self.db.task_counts()

    def weekly(self):
        """List of dicts: date, weekday (0=Sunday), completed_tasks, focus_minutes."""
        result = []
        for row in self.db.weekly_analytics():
            d = datetime.date.fromisoformat(row["d"])
            result.append({"date": d, "weekday": (d.weekday() + 1) % 7,
                           "completed_tasks": int(row["completed_tasks"]),
                           "focus_minutes": round(int(row["focus_seconds"]) / 60, 1)})
        return result

class FocusService:
    """Records focus periods using the active scoring policy."""

    def __init__(self, db, settings, policy):
        self.db = db
        self.settings = settings
        self.policy = policy

    def work_seconds(self):
        return self.settings.work_minutes() * 60

    def record(self, task_id, fraction, work_seconds=None):
        if task_id is None or fraction <= 0:
            return None
        result = self.policy.evaluate_session(fraction, work_seconds or self.work_seconds())
        self.db.add_focus_session(task_id, result.fraction, result.focus_seconds, result.reward)
        return result

    def task_focus_seconds(self, task_id):
        return self.db.get_task_focus_seconds(task_id)

    def remaining_seconds(self, task, live_seconds=0):
        """Seconds left on a task's estimate, or None if it has no estimate."""
        if not task or task["estimated_sessions"] is None:
            return None
        estimated = int(task["estimated_sessions"]) * self.work_seconds()
        return max(0, round(estimated - self.task_focus_seconds(task["id"]) - live_seconds))

    def estimated_minutes(self, task):
        if not task or task["estimated_sessions"] is None:
            return None
        return self.policy.estimated_minutes(task["estimated_sessions"], self.settings.work_minutes())

from dataclasses import dataclass
from typing import Optional


@dataclass
class TaskData:
    """Values coming from the task editor."""
    title: str
    priority: int = -1
    notes: str = ""
    start_at: Optional[str] = None
    end_at: Optional[str] = None
    estimated_sessions: Optional[int] = None


class TaskService:
    def __init__(self, db):
        self.db = db

    # queries
    def get(self, task_id):
        return self.db.get_task(task_id)

    def list(self, folder_id=None, priority=None, date_filter=None, selected_date=None, completed=None):
        return self.db.get_tasks(folder_id, priority, date_filter, selected_date, completed)

    def incomplete(self):
        return [t for t in self.db.get_tasks() if not t["completed"]]

    def current(self):
        return self.db.get_current_task()

    # commands
    def create(self, folder_id, data: TaskData, parent_id=None):
        return self.db.add_task(folder_id, data.title, data.priority, data.notes, data.start_at,
                                data.end_at, data.estimated_sessions, parent_id)

    def update(self, task_id, data: TaskData):
        self.db.update_task(task_id, data.title, data.priority, data.notes, data.start_at,
                            data.end_at, data.estimated_sessions)

    def delete(self, task_id):
        self.db.delete_task(task_id)

    def set_completed(self, task_id, completed: bool):
        self.db.set_completed(task_id, completed)

    def set_current(self, task_id):
        self.db.set_current_task(task_id)

    def schedule_on_day(self, task_id, day_iso: str):
        """Put an existing task on one calendar day (yyyy-MM-dd)."""
        task = self.get(task_id)
        if not task:
            return
        self.update(task_id, TaskData(task["title"], task["priority"], task["notes"] or "",
                                      day_iso + "T00:00:00", day_iso + "T23:59:00",
                                      task["estimated_sessions"]))

    # ---- subtasks (data layer ready; UI can be added in a later increment)
    def subtasks(self, parent_id):
        return self.db.get_subtasks(parent_id)

    def add_subtask(self, parent_id, title, priority=-1):
        parent = self.get(parent_id)
        if not parent:
            return None
        return self.create(parent["folder_id"], TaskData(title, priority), parent_id=parent_id)

    def subtask_progress(self, parent_id):
        subs = self.subtasks(parent_id)
        done = sum(1 for s in subs if s["completed"])
        return done, len(subs)

        self.title_input.setText(task["title"])
        self.priority_combo.setCurrentIndex(max(0, self.priority_combo.findData(task["priority"])))
        self.notes_input.setPlainText(task["notes"] or "")
        if task["estimated_sessions"] is not None:
            self.estimated_sessions.setValue(int(task["estimated_sessions"]))
            self.estimate_enabled.setChecked(True)
        if task["end_at"] or task["due_at"]:
            start = QDateTime.fromString(task["start_at"] or task["due_at"], Qt.ISODate)
            end = QDateTime.fromString(task["end_at"] or task["due_at"], Qt.ISODate)
            if start.isValid() and end.isValid():
                self.start_date.setDate(start.date())
                self.due_date.setDate(end.date())
                self.due_time.setTime(end.time())
                self.has_due.setChecked(True)

    def set_due_enabled(self, enabled):
        for w in (self.start_date, self.due_date, self.due_time):
            w.setEnabled(enabled)

    def validate(self):
        if not self.title_input.text().strip():
            QMessageBox.warning(self, tr("بيانات ناقصة"), tr("اكتب عنوان المهمة."))
            return
        if self.has_due.isChecked() and self.start_date.date() > self.due_date.date():
            QMessageBox.warning(self, tr("مدة غير صحيحة"), tr("تاريخ البداية يجب أن يسبق تاريخ النهاية."))
            return
        self.accept()

    def data(self) -> TaskData:
        start = end = None
        if self.has_due.isChecked():
            start = QDateTime(self.start_date.date(), QTime(0, 0)).toString(Qt.ISODate)
            end = QDateTime(self.due_date.date(), self.due_time.time()).toString(Qt.ISODate)
        return TaskData(
            title=self.title_input.text().strip(),
            priority=self.priority_combo.currentData(),
            notes=self.notes_input.toPlainText(),
            start_at=start,
            end_at=end,
            estimated_sessions=self.estimated_sessions.value() if self.estimate_enabled.isChecked() else None,
        )

PRIORITY_LABELS = {2: "عالية", 1: "متوسطة", 0: "منخفضة", -1: "غير محددة"}

WEEKDAYS = ["أحد", "اثنين", "ثلاثاء", "أربعاء", "خميس", "جمعة", "سبت"]  # Sunday = 0


def current_locale():
    return QLocale(qt_locale_name())


def locale_date_pattern():
    return current_locale().dateFormat(QLocale.ShortFormat)


def priority_label(value):
    return PRIORITY_LABELS.get(value, "غير محددة")


def format_minutes(value, short=False):
    value = max(0, round(float(value or 0)))
    hours, minutes = divmod(value, 60)
    if short:
        if hours and minutes:
            return f"{hours} س {minutes} د"
        return f"{hours} ساعة" if hours else f"{minutes} دقيقة"
    if hours and minutes:
        return f"{hours} ساعة و{minutes} دقيقة"
    return f"{hours} ساعة" if hours else f"{minutes} دقيقة"


def format_hms(seconds):
    hours, rest = divmod(max(0, int(seconds)), 3600)
    minutes, secs = divmod(rest, 60)
    return f"{hours:02d}:{minutes:02d}:{secs:02d}"


def format_sessions(task):
    done = float(task["completed_sessions"] or 0)
    done_text = f"{done:.2f}" if done % 1 else str(int(done))
    estimated = task["estimated_sessions"]
    return f"{done_text} / {int(estimated)} 🍅" if estimated is not None else f"{done_text} 🍅"


def format_range(task):
    start = task["start_at"] or task["due_at"]
    end = task["end_at"] or task["due_at"]
    if not end:
        return tr("بدون مدة")
    sd = QDateTime.fromString(start, Qt.ISODate)
    ed = QDateTime.fromString(end, Qt.ISODate)
    loc = current_locale()
    return f"{loc.toString(sd.date(), QLocale.ShortFormat)} ← {loc.toString(ed.date(), QLocale.ShortFormat)}"

def system_is_dark(app):
    try:
        return app.styleHints().colorScheme() == Qt.ColorScheme.Dark
    except Exception:
        return app.palette().color(QPalette.Window).lightness() < 128


def apply_theme(app, mode):
    effective = mode
    if mode == "system":
        effective = "dark" if system_is_dark(app) else "light"
    app.setStyleSheet(stylesheet(DARK if effective == "dark" else LIGHT))
    return effective

from PySide6.QtCore import QObject
from PySide6.QtGui import QAction, QIcon
from PySide6.QtWidgets import QMenu, QSystemTrayIcon

from flow_state import APP_NAME
from flow_state.i18n import tr


class TrayController(QObject):
    def __init__(self, window, timer):
        super().__init__()
        self.window = window
        self.timer = timer
        self.tray = QSystemTrayIcon()
        self.tray.setIcon(QIcon.fromTheme("appointment-new"))
        self.tray.setToolTip(APP_NAME)
        menu = QMenu()
        self.show_hide_action = QAction()
        self.start_pause_action = QAction()
        self.quit_action = QAction()
        menu.addAction(self.show_hide_action)
        menu.addAction(self.start_pause_action)
        menu.addSeparator()
        menu.addAction(self.quit_action)
        self.tray.setContextMenu(menu)
        self.menu = menu
        self.show_hide_action.triggered.connect(self.toggle_window)
        self.start_pause_action.triggered.connect(self.toggle_timer)
        self.quit_action.triggered.connect(self.window.close_application)
        self.timer.tick.connect(lambda text, _s: self.tray.setToolTip(f"{APP_NAME} | {text}"))
        self.timer.running_changed.connect(self.update_start_pause_text)
        self.retranslate()

    def show(self):
        self.tray.show()

    def toggle_window(self):
        if self.window.isVisible():
            self.window.hide()
        else:
            self.window.show()
            self.window.raise_()
            self.window.activateWindow()
        self.update_show_hide_text()

    def toggle_timer(self):
        self.timer.pause() if self.timer.is_running() else self.timer.start()

    def update_start_pause_text(self, running=None):
        running = self.timer.is_running() if running is None else running
        self.start_pause_action.setText(tr("إيقاف") if running else tr("ابدأ"))

    def update_show_hide_text(self):
        self.show_hide_action.setText(tr("إخفاء") if self.window.isVisible() else tr("عرض"))

    def retranslate(self):
        """QAction is not a QWidget, so translate_tree() cannot reach it."""
        self.update_show_hide_text()
        self.update_start_pause_text()
        self.quit_action.setText(tr("خروج"))

class WeeklyChart(QWidget):
    def __init__(self):
        super().__init__()
        self.values = [0] * 7
        self.labels = [""] * 7
        self.unit = ""
        self.color = ACCENTS["primary"]
        self.setMinimumHeight(250)

    def set_data(self, values, labels, unit="", color=None):
        self.values, self.labels, self.unit = list(values), list(labels), unit
        self.color = color or ACCENTS["primary"]
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.Antialiasing)
        text = self.palette().color(self.foregroundRole())
        grid = self.palette().color(self.backgroundRole()).lighter(125)
        w, h = self.width(), self.height()
        base = h - 45
        maximum = max(self.values + [1])
        gap = w / max(1, len(self.values))
        p.setPen(QPen(grid, 1))
        p.drawLine(18, base, w - 18, base)
        for i, value in enumerate(self.values):
            bh = (base - 38) * (value / maximum)
            rect = QRectF(i * gap + gap * .27, base - bh, gap * .46, bh)
            p.setPen(Qt.NoPen)
            p.setBrush(QColor(self.color))
            p.drawRoundedRect(rect, 6, 6)
            p.setPen(text)
            shown = f"{value:g}{self.unit}" if value else "0"
            p.drawText(QRectF(i * gap, base - bh - 24, gap, 20), Qt.AlignCenter, shown)
            p.drawText(QRectF(i * gap, base + 8, gap, 24), Qt.AlignCenter, self.labels[i])


class DonutChart(QWidget):
    def __init__(self):
        super().__init__()
        self.rate = 0
        self.caption = "إنجاز"
        self.color = ACCENTS["green"]
        self.setMinimumHeight(230)

    def set_data(self, rate, caption, color):
        self.rate = max(0, min(100, float(rate)))
        self.caption, self.color = caption, color
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.Antialiasing)
        side = max(30, min(self.width(), self.height()) - 58)
        rect = QRectF((self.width() - side) / 2, (self.height() - side) / 2, side, side)
        track = self.palette().color(self.backgroundRole()).lighter(130)
        text = self.palette().color(self.foregroundRole())
        p.setPen(QPen(track, 18, Qt.SolidLine, Qt.RoundCap))
        p.drawArc(rect, 0, 360 * 16)
        p.setPen(QPen(QColor(self.color), 18, Qt.SolidLine, Qt.RoundCap))
        p.drawArc(rect, 90 * 16, -int(360 * 16 * self.rate / 100))
        p.setPen(text)
        p.drawText(rect, Qt.AlignCenter, f"{round(self.rate)}%\n{self.caption}")

from PySide6.QtCore import Signal

class FolderPanel(QWidget):
    folder_selected = Signal(int)
    folders_changed = Signal()

    def __init__(self, services):
        super().__init__()
        self.folders = services.folders
        self.setObjectName("folderPanel")
        self.folder_ids = []
        layout = QVBoxLayout(self)
        layout.setContentsMargins(14, 18, 14, 14)
        layout.setSpacing(10)
        self.list_widget = QListWidget()
        layout.addWidget(self.list_widget)
        buttons = QHBoxLayout()
        self.add_button = QPushButton("＋ جديد")
        self.delete_button = QPushButton("حذف")
        self.add_button.setObjectName("primary")
        self.delete_button.setObjectName("danger")
        buttons.addWidget(self.add_button)
        buttons.addWidget(self.delete_button)
        layout.addLayout(buttons)
        self.add_button.clicked.connect(self.add_folder)
        self.delete_button.clicked.connect(self.delete_folder)
        self.list_widget.currentRowChanged.connect(self.on_current_row_changed)
        self.reload()

    def reload(self):
        self.list_widget.clear()
        self.folder_ids = []
        for folder in self.folders.list():
            self.folder_ids.append(folder["id"])
            self.list_widget.addItem(folder["name"])
        if self.folder_ids and self.list_widget.currentRow() == -1:
            self.list_widget.setCurrentRow(0)
        translate_tree(self)

    def current_folder_id(self):
        row = self.list_widget.currentRow()
        return self.folder_ids[row] if 0 <= row < len(self.folder_ids) else None

    def on_current_row_changed(self, row):
        if 0 <= row < len(self.folder_ids):
            self.folder_selected.emit(self.folder_ids[row])

    def add_folder(self):
        name, ok = QInputDialog.getText(self, tr("إضافة مجلد"), tr("اسم المجلد:"))
        if ok and name.strip():
            self.folders.add(name)
            self.reload()
            self.folders_changed.emit()

    def delete_folder(self):
        folder_id = self.current_folder_id()
        if folder_id is None:
            return
        reply = QMessageBox.question(self, tr("حذف المجلد"), tr("هل تريد حذف هذا المجلد وكل مهامه؟"),
                                     QMessageBox.Yes | QMessageBox.No)
        if reply == QMessageBox.Yes:
            self.folders.delete(folder_id)
            self.reload()
            self.folders_changed.emit()

    def open_add_dialog(self, default_date=None):

            QMessageBox.information(self, tr("لا توجد مهام"), tr("أضف مهمة غير مكتملة أولًا."))

        task_id = ChooseTaskDialog.ask(rows, "تغيير المهمة الحالية", "اختر المهمة التي تريد التركيز عليها:", self)

    def item_changed(self, item):
        if item.column() == COL_DONE and item.row() in self.row_task_ids:
            self.tasks.set_completed(self.row_task_ids[item.row()], item.checkState() == Qt.Checked)
            self._changed()

        self.reload_tasks()
        self.task_changed.emit()
        if current_too:
            self.current_task_changed.emit()

    def toggle_completed(self):
        self.show_completed = not self.show_completed

    # ------------------------------------------------------------- render
    def reload_tasks(self):
        self.table.blockSignals(True)
        self.table.clearSpans()
        self.table.setRowCount(0)
        self.row_task_ids = {}
        args = (self.folder_id, self.priority_filter, self.date_filter, self.selected_date)
        active = self.tasks.list(*args, completed=False)
        completed = self.tasks.list(*args, completed=True)
        row = 0
        for task in active:
            self._add_task_row(row, task)
            row += 1
        if completed:
            self.table.insertRow(row)
            self.table.setSpan(row, 0, 1, len(COLUMNS))
            toggle = QPushButton(("▲ " + tr("إخفاء") if self.show_completed else "▼ " + tr("عرض"))
                                 + f" {tr('المهام المكتملة')} ({len(completed)})")
            toggle.setObjectName("nav")
            toggle.clicked.connect(self.toggle_completed)
            self.table.setCellWidget(row, 0, toggle)
            self.table.setRowHeight(row, 42)
            row += 1
            if self.show_completed:
                for task in completed:
                    self._add_task_row(row, task)
                    row += 1
        if not active and not completed:
            self.table.setRowCount(1)
            empty = QTableWidgetItem(tr("لا توجد مهام في هذا العرض."))
            empty.setTextAlignment(Qt.AlignCenter)
            self.table.setSpan(0, 0, 1, len(COLUMNS))
            self.table.setItem(0, 0, empty)
        self.table.blockSignals(False)
        translate_tree(self)

    def _add_task_row(self, row, task):
        self.table.insertRow(row)
        tid = task["id"]
        self.row_task_ids[row] = tid
        done = QTableWidgetItem()
        done.setFlags(Qt.ItemIsUserCheckable | Qt.ItemIsEnabled)
        done.setCheckState(Qt.Checked if task["completed"] else Qt.Unchecked)
        self.table.setItem(row, COL_DONE, done)
        title = QTableWidgetItem(task["title"])
        if task["completed"]:
            title.setForeground(QColor("gray"))
            font = title.font()
            font.setStrikeOut(True)
            title.setFont(font)
        self.table.setItem(row, COL_TITLE, title)
        self.table.setItem(row, COL_RANGE, QTableWidgetItem(format_range(task)))
        priority = QTableWidgetItem(tr(priority_label(task["priority"])))
        priority.setForeground(QColor(PRIORITY_COLORS.get(task["priority"], "#ffffff")))
        self.table.setItem(row, COL_PRIORITY, priority)
        self.table.setItem(row, COL_SESSIONS, QTableWidgetItem(format_sessions(task)))
        focus = QPushButton(tr("الحالية") if task["is_current"] else tr("اختيار"))
        focus.setEnabled(not task["is_current"] and not task["completed"])
        focus.clicked.connect(lambda _=False, t=tid: self.set_current_task(t))
        self.table.setCellWidget(row, COL_FOCUS, focus)
        edit = QPushButton(tr("تعديل"))
        edit.clicked.connect(lambda _=False, t=tid: self.edit_task(t))
        self.table.setCellWidget(row, COL_EDIT, edit)
        delete = QPushButton(tr("حذف"))
        delete.setObjectName("danger")
        delete.clicked.connect(lambda _=False, t=tid: self.delete_task(t))
        self.table.setCellWidget(row, COL_DELETE, delete)

    # ------------------------------------------------------------ columns
    def apply_column_mode(self):
        settings = self.services.settings
        header = self.table.horizontalHeader()
        header.setStretchLastSection(False)
        if settings.get("auto_columns", "1") == "1":
            for col in range(self.table.columnCount()):
                header.setSectionResizeMode(col, QHeaderView.ResizeToContents)
            header.setSectionResizeMode(COL_TITLE, QHeaderView.Stretch)
            return
        for col in range(self.table.columnCount()):
            header.setSectionResizeMode(col, QHeaderView.Interactive)
        raw = settings.get("task_column_widths", "")
        if raw:
            try:
                for col, width in enumerate(int(x) for x in raw.split(",")):
                    if col < self.table.columnCount():
                        self.table.setColumnWidth(col, max(35, width))
            except ValueError:
                pass

    def save_column_widths(self):
        if self.services.settings.get("auto_columns", "1") == "0":
            widths = ",".join(str(self.table.columnWidth(i)) for i in range(self.table.columnCount()))
            self.services.settings.set("task_column_widths", widths)

from PySide6.QtCore import QRectF, Qt
from PySide6.QtGui import QColor, QPainter, QPen
from PySide6.QtWidgets import QWidget


class TimerRing(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.progress = 1.0
        self.setMinimumSize(250, 250)

    def set_progress(self, value):
        self.progress = max(0.0, min(1.0, value))
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.Antialiasing)
        side = min(self.width(), self.height()) - 24
        rect = QRectF((self.width() - side) / 2, (self.height() - side) / 2, side, side)
        p.setPen(QPen(QColor("#dfe3f4"), 10, Qt.SolidLine, Qt.RoundCap))
        p.drawArc(rect, 0, 360 * 16)
        p.setPen(QPen(QColor("#626cf2"), 10, Qt.SolidLine, Qt.RoundCap))
        p.drawArc(rect, 90 * 16, -int(360 * 16 * self.progress))
